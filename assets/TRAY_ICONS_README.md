# Tray Icon Assets

This directory contains the system tray icons for LegalApp.

## Required Icons

### tray-active.png
- **Color**: Brand blue #1F4E79
- **Sizes**: 16x16 and 32x32 (for HiDPI displays)
- **Usage**: Displayed when time tracking is active
- **Design**: Simple clock or timer icon in brand color

### tray-idle.png
- **Color**: Gray #808080
- **Sizes**: 16x16 and 32x32 (for HiDPI displays)
- **Usage**: Displayed when time tracking is paused/idle
- **Design**: Same clock/timer icon but grayed out

## File Format
- PNG with transparency
- For multi-resolution support, use @2x naming convention:
  - tray-active.png (16x16)
  - tray-active@2x.png (32x32)
  - tray-idle.png (16x16)
  - tray-idle@2x.png (32x32)
